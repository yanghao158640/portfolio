# Open-source visual foundations

The portfolio layout, film exhibition and artwork composition are custom-designed for 杨豫豪.

- **Motion / Framer Motion** — https://github.com/motiondivision/motion — MIT. The existing dependency supplies viewport reveals and staggered episode entrances.
- **Lenis 1.3.17** — https://github.com/darkroomengineering/lenis — MIT. Desktop wheel smoothing and anchor navigation, disabled for reduced motion.
- **Lucide** — https://github.com/lucide-icons/lucide — ISC. Existing icon dependency.

License notices are distributed in the respective npm packages. React Bits (https://github.com/DavidHDev/react-bits) was reviewed during visual research; its code was not incorporated. All film imagery is extracted from the five videos supplied by the site owner.
